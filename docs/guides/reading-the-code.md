# Reading the code, step by step

**The short answer.** <span style="color:grey">Read</span> the <span style="color:grey">code</span> in the <span style="color:grey">order</span> a <span style="color:grey">request</span> <span style="color:grey">travels</span>. <span style="color:grey">Part</span> A <span style="color:grey">follows</span> <span style="color:grey">one</span> ***tile*** from the <span style="color:grey">office</span>'s <span style="color:grey">browser</span>, <span style="color:grey">through</span> Nginx and the <span style="color:grey">service</span>, to the <span style="color:grey">database</span> and <span style="color:grey">back</span>. <span style="color:grey">Part</span> B <span style="color:grey">follows</span> the <span style="color:grey">map</span>'s <span style="color:grey">page</span> as it <span style="color:grey">opens</span> in the <span style="color:grey">browser</span> and <span style="color:grey">draws</span> that <span style="color:grey">tile</span>. <span style="color:grey">Each</span> <span style="color:grey">step</span> <span style="color:grey">names</span> the <span style="color:grey">files</span> to <span style="color:grey">open</span>, what to <span style="color:grey">look</span> for, and <span style="color:grey">one</span> <span style="color:grey">question</span> to <span style="color:grey">check</span> yourself. <span style="color:grey">Fifteen</span> <span style="color:grey">steps</span> <span style="color:grey">take</span> an <span style="color:grey">afternoon</span>; the backend is <span style="color:grey">about</span> 1,200 <span style="color:grey">lines</span> of C#, and the <span style="color:grey">map</span> <span style="color:grey">about</span> 3,000 <span style="color:grey">lines</span> of TypeScript, <span style="color:grey">beside</span> their <span style="color:grey">tests</span>.

**Before you start.** <span style="color:grey">Run</span> `npm test` <span style="color:grey">once</span>, so you <span style="color:grey">know</span> every <span style="color:grey">part</span> <span style="color:grey">works</span>, then <span style="color:grey">keep</span> <span style="color:grey">two</span> terminals <span style="color:grey">open</span>: <span style="color:grey">one</span> for `npm start`, <span style="color:grey">one</span> for `curl`. <span style="color:grey">Seeing</span> an <span style="color:grey">answer</span> <span style="color:grey">arrive</span> <span style="color:grey">teaches</span> <span style="color:grey">faster</span> than <span style="color:grey">reading</span> <span style="color:grey">about</span> it.

## Part A · The backend: one tile, from request to bytes

### Step 1 · How the program starts

- **Open:** `src/Tessera/Program.cs`.
- **Look for:** the `switch` on the <span style="color:grey">arguments</span>. No <span style="color:grey">argument</span> <span style="color:grey">serves</span> <span style="color:grey">tiles</span>; `seed` <span style="color:grey">loads</span> the <span style="color:grey">places</span> and <span style="color:grey">stops</span>. Every <span style="color:grey">failure</span> <span style="color:grey">ends</span> with a <span style="color:grey">list</span> of <span style="color:grey">problems</span> and exit <span style="color:grey">code</span> 1, or 2 for a <span style="color:grey">command</span> it does not <span style="color:grey">understand</span>.
- **Check yourself:** what does `Tessera seed` <span style="color:grey">sign</span> in as, and why not as the <span style="color:grey">reader</span>?

### Step 2 · How the service is put together

- **Open:** `src/Tessera/Service.cs`, then `src/Tessera/Tessera.csproj` and <span style="color:grey">one</span> ***module***'s <span style="color:grey">project</span> <span style="color:grey">file</span>, such as `src/Tessera/Tiles/Tessera.Tiles.csproj`.
- **Look for:** <span style="color:grey">two</span> <span style="color:grey">halves</span>. <span style="color:grey">Before</span> `builder.Build()`, the <span style="color:grey">code</span> <span style="color:grey">fills</span> the <span style="color:grey">table</span> of <span style="color:grey">services</span>: the <span style="color:grey">settings</span>, the <span style="color:grey">database</span> <span style="color:grey">pool</span>, the <span style="color:grey">list</span> of ***layers***, the <span style="color:grey">health</span> <span style="color:grey">check</span>. <span style="color:grey">After</span> it, the <span style="color:grey">code</span> <span style="color:grey">lays</span> the ***pipeline*** every <span style="color:grey">request</span> <span style="color:grey">passes</span> <span style="color:grey">through</span>, in <span style="color:grey">order</span>: the <span style="color:grey">error</span> <span style="color:grey">handlers</span>, the <span style="color:grey">map</span>'s <span style="color:grey">headers</span>, `/health`, the <span style="color:grey">tiles</span>, the <span style="color:grey">map</span>. Then the <span style="color:grey">project</span> <span style="color:grey">files</span>: the <span style="color:grey">program</span> <span style="color:grey">names</span> every <span style="color:grey">module</span>, and <span style="color:grey">each</span> <span style="color:grey">module</span> <span style="color:grey">names</span> <span style="color:grey">only</span> the <span style="color:grey">modules</span> it may <span style="color:grey">use</span>, so the <span style="color:grey">compiler</span> <span style="color:grey">refuses</span> <span style="color:grey">any</span> <span style="color:grey">other</span> (ADR 0001).
- **Check yourself:** what does `/health` <span style="color:grey">answer</span> <span style="color:grey">while</span> the <span style="color:grey">list</span> of <span style="color:grey">layers</span> is <span style="color:grey">still</span> <span style="color:grey">loading</span>?

### Step 3 · Where the settings come from

- **Open:** `tessera.json`, then `src/Tessera/Settings/Settings.cs`, with `docs/guides/reading-the-harder-files.md` <span style="color:grey">beside</span> you.
- **Look for:** <span style="color:grey">one</span> <span style="color:grey">record</span> for <span style="color:grey">each</span> <span style="color:grey">section</span> of `tessera.json`, its <span style="color:grey">defaults</span> in the <span style="color:grey">record</span>, its <span style="color:grey">limits</span> in `[Range]`, and `Check`, which <span style="color:grey">names</span> every <span style="color:grey">problem</span> at <span style="color:grey">once</span>.
- **Check yourself:** <span style="color:grey">set</span> `Tiles__CacheSeconds=-1` and <span style="color:grey">run</span> the <span style="color:grey">program</span>. What does it <span style="color:grey">print</span>?

### Step 4 · What Nginx does before the service sees a request

- **Open:** `nginx/default.conf.template`, and ADR 0008.
- **Look for:** <span style="color:grey">first</span> the `geo` <span style="color:grey">block</span> and the `if` that <span style="color:grey">refuses</span> a <span style="color:grey">machine</span> <span style="color:grey">outside</span> the <span style="color:grey">office</span>, and the <span style="color:grey">limits</span> for <span style="color:grey">each</span> <span style="color:grey">visitor</span> (ADR 0007); then the `upstream` <span style="color:grey">group</span> of <span style="color:grey">two</span> <span style="color:grey">copies</span>; then the `location` for <span style="color:grey">tiles</span>. Nginx <span style="color:grey">keeps</span> <span style="color:grey">each</span> <span style="color:grey">tile</span>, <span style="color:grey">answers</span> 304, <span style="color:grey">packs</span> with gzip, <span style="color:grey">refuses</span> a <span style="color:grey">malformed</span> <span style="color:grey">address</span>, <span style="color:grey">passes</span> a <span style="color:grey">request</span> to the <span style="color:grey">other</span> <span style="color:grey">copy</span> when <span style="color:grey">one</span> <span style="color:grey">fails</span>, and <span style="color:grey">serves</span> <span style="color:grey">kept</span> <span style="color:grey">tiles</span> <span style="color:grey">while</span> both are <span style="color:grey">down</span>. The <span style="color:grey">service</span> <span style="color:grey">never</span> does these <span style="color:grey">jobs</span>.
- **Check yourself:** <span style="color:grey">ask</span> for the <span style="color:grey">same</span> <span style="color:grey">tile</span> <span style="color:grey">twice</span> with `curl -I`. What does `X-Cache-Status` <span style="color:grey">say</span> <span style="color:grey">each</span> <span style="color:grey">time</span>?

### Step 5 · The tile route

- **Open:** `src/Tessera/Tiles/Tiles.cs`.
- **Look for:** the <span style="color:grey">path</span> a <span style="color:grey">request</span> <span style="color:grey">takes</span>. `MapTiles` <span style="color:grey">matches</span> `/{layer}/{z}/{x}/{y}.pbf`; `TileAddress.Of` <span style="color:grey">refuses</span> a <span style="color:grey">tile</span> <span style="color:grey">outside</span> the <span style="color:grey">grid</span>; `TileServer.Answer` <span style="color:grey">finds</span> the <span style="color:grey">layer</span>, <span style="color:grey">runs</span> the <span style="color:grey">query</span>, and <span style="color:grey">returns</span> the <span style="color:grey">bytes</span> with `Cache-Control` and an `ETag`. <span style="color:grey">Each</span> <span style="color:grey">failure</span> <span style="color:grey">becomes</span> a ***problem document*** from `Problems.cs`: 404 for no such <span style="color:grey">layer</span> or <span style="color:grey">tile</span>, 503 <span style="color:grey">while</span> the <span style="color:grey">database</span> <span style="color:grey">cannot</span> <span style="color:grey">answer</span>.
- **Check yourself:** why does a <span style="color:grey">revoked</span> ***grant*** <span style="color:grey">answer</span> 404 <span style="color:grey">rather</span> than 500?

### Step 6 · Where the list of layers comes from

- **Open:** `src/Tessera/Catalogue/Catalogue.cs`, and US-03 and N-23 in the <span style="color:grey">stories</span>.
- **Look for:** `LayerCatalogue`, <span style="color:grey">one</span> <span style="color:grey">list</span> at <span style="color:grey">one</span> <span style="color:grey">moment</span>, and `LiveCatalogue`, which <span style="color:grey">rereads</span> it every `Catalogue.RefreshSeconds`. A <span style="color:grey">table</span> <span style="color:grey">becomes</span> a <span style="color:grey">layer</span> <span style="color:grey">only</span> when the <span style="color:grey">reader</span> ***role*** may <span style="color:grey">read</span> it, so a <span style="color:grey">grant</span> <span style="color:grey">publishes</span> and a <span style="color:grey">revoke</span> withdraws.
- **Check yourself:** the <span style="color:grey">database</span> blinks <span style="color:grey">during</span> a refresh. Does the <span style="color:grey">map</span> <span style="color:grey">lose</span> its <span style="color:grey">layers</span>?

### Step 7 · Every SQL text, and the one door to PostgreSQL

- **Open:** `src/Tessera/Sql/Queries.cs`, then `src/Tessera/Sql/Database.cs`.
- **Look for:** in `Queries.cs`, the ***tile query***: `ST_TileEnvelope` <span style="color:grey">makes</span> the <span style="color:grey">tile</span>'s <span style="color:grey">square</span>, `ST_AsMVTGeom` <span style="color:grey">fits</span> <span style="color:grey">each</span> <span style="color:grey">place</span> into it, `ST_AsMVT` <span style="color:grey">packs</span> the <span style="color:grey">tile</span>. Every <span style="color:grey">value</span> <span style="color:grey">travels</span> as a ***parameter*** such as `@z`; every <span style="color:grey">name</span> <span style="color:grey">goes</span> <span style="color:grey">through</span> `Quote` (S-01). In `Database.cs`, `Run`, which <span style="color:grey">borrows</span> a <span style="color:grey">connection</span> from the <span style="color:grey">pool</span> and <span style="color:grey">turns</span> <span style="color:grey">each</span> <span style="color:grey">failure</span> into a `Result`.
- **Check yourself:** `tests/Tessera.UnitTests/approved/tile-query.sql` <span style="color:grey">holds</span> the <span style="color:grey">approved</span> <span style="color:grey">text</span>. Why does a <span style="color:grey">test</span> <span style="color:grey">compare</span> the <span style="color:grey">query</span> with it?

### Step 8 · How the page reaches the browser

- **Open:** `src/Tessera/Map/Map.cs`.
- **Look for:** `/` and `/{layer}.html` both <span style="color:grey">answer</span> the <span style="color:grey">same</span> <span style="color:grey">page</span>, `web/dist/index.html`, with the <span style="color:grey">area</span> <span style="color:grey">written</span> in as a <span style="color:grey">block</span> of JSON by `Render`. The <span style="color:grey">page</span>'s <span style="color:grey">files</span> <span style="color:grey">under</span> `/assets` are <span style="color:grey">kept</span> for a <span style="color:grey">year</span>, <span style="color:grey">since</span> <span style="color:grey">each</span> <span style="color:grey">name</span> <span style="color:grey">carries</span> a hash of its <span style="color:grey">content</span>.
- **Check yourself:** `curl` the <span style="color:grey">page</span> and <span style="color:grey">find</span> the `tessera-area` <span style="color:grey">block</span>. Where does its <span style="color:grey">box</span> <span style="color:grey">come</span> from?

### Step 9 · How the places enter the database

- **Open:** `data/macau.pipeline.json`, then `tools/Tessera.Etl/Program.cs`, `Chain.cs` and <span style="color:grey">one</span> ***filter*** in `Filters/`, such as `InsideArea.cs`, `db/seed/0001-macau-places.sql` (the <span style="color:grey">first</span> <span style="color:grey">lines</span> <span style="color:grey">alone</span>), `src/Tessera/Seeding/SeedScripts.cs`, and ADR 0009.
- **Look for:** GDAL extracts <span style="color:grey">each</span> <span style="color:grey">table</span> to GeoJSON, the ***pipeline file***'s filters, <span style="color:grey">joined</span> into <span style="color:grey">one</span> with `>>`, <span style="color:grey">clean</span> its <span style="color:grey">rows</span> in <span style="color:grey">turn</span>, and GDAL <span style="color:grey">writes</span> the <span style="color:grey">cleaned</span> <span style="color:grey">rows</span> as SQL; DbUp <span style="color:grey">runs</span> <span style="color:grey">each</span> <span style="color:grey">new</span> <span style="color:grey">script</span> <span style="color:grey">once</span> and <span style="color:grey">records</span> it in `tessera.schemaversions`; `npm run publish` <span style="color:grey">grants</span> the <span style="color:grey">tables</span>.
- **Check yourself:** you <span style="color:grey">find</span> a <span style="color:grey">wrong</span> <span style="color:grey">address</span> in a <span style="color:grey">script</span> that has <span style="color:grey">run</span>. What do you <span style="color:grey">change</span>?

## Part B · The frontend: the page opens and draws a tile

### Step 10 · The first code the browser runs

- **Open:** `web/index.html`, then `web/src/main.tsx` and `web/src/app/mount.tsx`.
- **Look for:** `main.tsx` <span style="color:grey">reads</span> the <span style="color:grey">area</span> from the `tessera-area` <span style="color:grey">block</span>, <span style="color:grey">works</span> out which <span style="color:grey">layer</span> the <span style="color:grey">address</span> <span style="color:grey">names</span>, and mounts `App`. `mount.tsx` <span style="color:grey">swaps</span> in a <span style="color:grey">short</span> <span style="color:grey">message</span> when an <span style="color:grey">error</span> escapes the <span style="color:grey">whole</span> <span style="color:grey">page</span> (US-23 c9).
- **Check yourself:** <span style="color:grey">open</span> the <span style="color:grey">page</span> <span style="color:grey">without</span> the <span style="color:grey">service</span>, <span style="color:grey">under</span> `npm run dev` in `web/`. Which <span style="color:grey">area</span> does it <span style="color:grey">show</span>, and why?

### Step 11 · The heart of the map: one model, one update

- **Open:** `web/src/map/map.ts`, then `web/src/app/App.tsx`.
- **Look for:** the Elmish <span style="color:grey">pattern</span>. `Model` <span style="color:grey">holds</span> <span style="color:grey">everything</span> the <span style="color:grey">page</span> <span style="color:grey">shows</span>; `Msg` <span style="color:grey">lists</span> <span style="color:grey">everything</span> that can <span style="color:grey">happen</span>; `update` <span style="color:grey">makes</span> the <span style="color:grey">next</span> <span style="color:grey">model</span> from the <span style="color:grey">old</span> <span style="color:grey">one</span> and a <span style="color:grey">message</span>, and <span style="color:grey">changes</span> <span style="color:grey">nothing</span> <span style="color:grey">else</span> (ADR 0004). <span style="color:grey">Work</span> <span style="color:grey">outside</span>, such as <span style="color:grey">moving</span> the <span style="color:grey">map</span>, <span style="color:grey">goes</span> out <span style="color:grey">through</span> `Ports`. `App.tsx` <span style="color:grey">runs</span> the loop with `useElmish` and <span style="color:grey">lays</span> out the <span style="color:grey">parts</span>.
- **Check yourself:** <span style="color:grey">find</span> the <span style="color:grey">message</span> a <span style="color:grey">click</span> on 'zoom in' <span style="color:grey">sends</span>, and <span style="color:grey">follow</span> it <span style="color:grey">through</span> `update`. What <span style="color:grey">leaves</span> <span style="color:grey">through</span> the <span style="color:grey">ports</span>?

### Step 12 · The nine layers and the map's style

- **Open:** `web/src/layers/layers.ts`, then `web/src/map/style.ts`.
- **Look for:** the <span style="color:grey">nine</span> <span style="color:grey">layers</span> <span style="color:grey">live</span> in the <span style="color:grey">map</span>'s <span style="color:grey">own</span> <span style="color:grey">code</span>; <span style="color:grey">each</span> <span style="color:grey">tile</span>'s <span style="color:grey">address</span> is `/{layer}/{z}/{x}/{y}.pbf` on the <span style="color:grey">page</span>'s <span style="color:grey">own</span> <span style="color:grey">origin</span>. `buildStyle` is a ***pure function*** that <span style="color:grey">turns</span> the <span style="color:grey">model</span> into MapLibre's <span style="color:grey">style</span>: a <span style="color:grey">plain</span> <span style="color:grey">background</span>, then the <span style="color:grey">names</span>, the <span style="color:grey">pins</span> and the ***clusters***.
- **Check yourself:** where would you <span style="color:grey">add</span> a tenth <span style="color:grey">layer</span>, and what <span style="color:grey">else</span> would <span style="color:grey">need</span> it?

### Step 13 · Where the map meets MapLibre

- **Open:** `web/src/map/MapCanvas.tsx`, `web/src/map/canvas-hooks.ts`, `web/src/map/maplibre.ts`, then `web/src/map/places.ts`.
- **Look for:** the <span style="color:grey">shell</span> <span style="color:grey">around</span> the <span style="color:grey">pure</span> <span style="color:grey">core</span>. `canvas-hooks.ts` <span style="color:grey">holds</span> <span style="color:grey">four</span> <span style="color:grey">named</span> hooks: <span style="color:grey">one</span> <span style="color:grey">makes</span> the <span style="color:grey">map</span> and wires its <span style="color:grey">events</span>, <span style="color:grey">one</span> <span style="color:grey">keeps</span> the <span style="color:grey">style</span> in <span style="color:grey">step</span>, <span style="color:grey">one</span> <span style="color:grey">runs</span> the <span style="color:grey">pins</span>' <span style="color:grey">drop</span>, <span style="color:grey">one</span> <span style="color:grey">keeps</span> the <span style="color:grey">newest</span> props. `maplibre.ts` <span style="color:grey">holds</span> MapLibre's <span style="color:grey">options</span> and <span style="color:grey">events</span>. `places.ts` <span style="color:grey">joins</span> the <span style="color:grey">places</span> of every <span style="color:grey">loaded</span> <span style="color:grey">tile</span> into <span style="color:grey">one</span> <span style="color:grey">list</span>, which MapLibre clusters in the <span style="color:grey">browser</span> (ADR 0005).
- **Check yourself:** a <span style="color:grey">place</span> <span style="color:grey">near</span> a <span style="color:grey">tile</span>'s <span style="color:grey">edge</span> <span style="color:grey">arrives</span> in <span style="color:grey">two</span> <span style="color:grey">tiles</span>. ### Step 14 · The shared kernel and the design

- **Open:** `web/src/shared/result.ts`, `web/src/shared/area.ts`, then `web/src/design/theme.ts`.
- **Look for:** `Result`, the <span style="color:grey">same</span> <span style="color:grey">idea</span> as the backend's, with F#'s <span style="color:grey">function</span> <span style="color:grey">names</span>. `areaOf` <span style="color:grey">reads</span> the <span style="color:grey">area</span> <span style="color:grey">through</span> Valibot, which <span style="color:grey">checks</span> <span style="color:grey">data</span> <span style="color:grey">against</span> a <span style="color:grey">description</span> of its <span style="color:grey">shape</span>, and <span style="color:grey">falls</span> <span style="color:grey">back</span> to Macau. `design/` <span style="color:grey">holds</span> the <span style="color:grey">colours</span>, <span style="color:grey">shapes</span> and motion of Material 3.

### Step 15 · The tests as a map of the rules
