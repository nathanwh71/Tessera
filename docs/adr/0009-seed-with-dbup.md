# ADR 0009: Clean the places in a C# pipeline, and seed the database with DbUp

| | |
|---|---|
| Status | <span style="color:grey">Accepted</span> |
| Date | 15 <span style="color:grey">October</span> 2026 |
| Decider | The <span style="color:grey">maintainer</span> |
| Covers | The <span style="color:grey">service</span>, `nathanwh71/Tessera`; its ***pipeline***, `tools/Tessera.Etl`; and its ***seed scripts*** in `db/seed` |
| Related | ADR 0001, ADR 0002, ADR 0004, ADR 0008; US-01, US-03, US-24 |

## Decision

A <span style="color:grey">pipeline</span> in C#, `tools/Tessera.Etl`, <span style="color:grey">turns</span> <span style="color:grey">each</span> <span style="color:grey">file</span> of <span style="color:grey">places</span> into a SQL <span style="color:grey">script</span> in <span style="color:grey">three</span> <span style="color:grey">steps</span>. GDAL's `ogr2ogr` **extracts** <span style="color:grey">each</span> <span style="color:grey">table</span> to GeoJSON; ***filters*** the ***pipeline file*** <span style="color:grey">names</span> **transform** its <span style="color:grey">rows</span>, <span style="color:grey">cleaning</span> them; and `ogr2ogr` **loads** the <span style="color:grey">cleaned</span> <span style="color:grey">rows</span> as SQL. The <span style="color:grey">maintainer</span> <span style="color:grey">reads</span> the <span style="color:grey">script</span> and its <span style="color:grey">log</span>, and <span style="color:grey">commits</span> both. `Tessera seed`, <span style="color:grey">signed</span> in as `tessera_publisher`, <span style="color:grey">runs</span> <span style="color:grey">each</span> <span style="color:grey">script</span> DbUp has not <span style="color:grey">run</span> <span style="color:grey">before</span>, <span style="color:grey">once</span>, in the <span style="color:grey">order</span> of the <span style="color:grey">scripts</span>' <span style="color:grey">names</span>. A ***grant*** <span style="color:grey">publishes</span> <span style="color:grey">each</span> <span style="color:grey">table</span>.

## Why

- **Many shapes, no new code.** The <span style="color:grey">maintainer</span> <span style="color:grey">owns</span> spatial <span style="color:grey">data</span> in <span style="color:grey">several</span> <span style="color:grey">shapes</span>, <span style="color:grey">each</span> with <span style="color:grey">columns</span> of its <span style="color:grey">own</span>, from ArcGIS <span style="color:grey">file</span> ***geodatabases*** to GeoJSON. `ogr2ogr` <span style="color:grey">reads</span> more than eighty <span style="color:grey">formats</span>, <span style="color:grey">makes</span> a <span style="color:grey">table</span> to <span style="color:grey">fit</span> <span style="color:grey">each</span> <span style="color:grey">file</span>, and reprojects as it <span style="color:grey">reads</span>.
- **Clean before it lands.** <span style="color:grey">Real</span> <span style="color:grey">data</span> <span style="color:grey">holds</span> <span style="color:grey">empty</span> <span style="color:grey">shapes</span>, invalid <span style="color:grey">areas</span>, <span style="color:grey">swapped</span> longitude and latitude, stray <span style="color:grey">spaces</span>, <span style="color:grey">missing</span> <span style="color:grey">names</span> and <span style="color:grey">places</span> <span style="color:grey">entered</span> <span style="color:grey">twice</span>. A filter <span style="color:grey">catches</span> <span style="color:grey">each</span> <span style="color:grey">before</span> it <span style="color:grey">reaches</span> a <span style="color:grey">script</span>, and the <span style="color:grey">log</span> <span style="color:grey">names</span> every <span style="color:grey">row</span> it touched.
- **Stop rather than guess.** A filter <span style="color:grey">set</span> to <span style="color:grey">stop</span>, or a <span style="color:grey">table</span> that <span style="color:grey">loses</span> <span style="color:grey">too</span> <span style="color:grey">many</span> <span style="color:grey">rows</span>, <span style="color:grey">ends</span> the <span style="color:grey">run</span> with no <span style="color:grey">script</span> <span style="color:grey">written</span>, so <span style="color:grey">bad</span> <span style="color:grey">data</span> <span style="color:grey">never</span> <span style="color:grey">reaches</span> the <span style="color:grey">database</span> by <span style="color:grey">default</span>.
- **C#, beside the service.** The filters are ***pure functions*** in the <span style="color:grey">style</span> of ADR 0004, <span style="color:grey">tested</span> in <span style="color:grey">seconds</span> with no <span style="color:grey">files</span>. NetTopologySuite, the .NET <span style="color:grey">port</span> of the geometry <span style="color:grey">library</span> <span style="color:grey">behind</span> PostGIS, <span style="color:grey">measures</span> and <span style="color:grey">repairs</span> the <span style="color:grey">shapes</span>.
- **SQL to read, once.** DbUp <span style="color:grey">runs</span> <span style="color:grey">each</span> <span style="color:grey">script</span> <span style="color:grey">once</span> and <span style="color:grey">records</span> it; its PostgreSQL <span style="color:grey">package</span> has 24.6 million <span style="color:grey">downloads</span>. A <span style="color:grey">script</span> is <span style="color:grey">plain</span> SQL, so the <span style="color:grey">maintainer</span> <span style="color:grey">reads</span> <span style="color:grey">exactly</span> what will <span style="color:grey">enter</span> the <span style="color:grey">database</span> <span style="color:grey">before</span> it does.

## How it works

| Step | Run by | What happens |
|---|---|---|
| Inspect | `npm run inspect -- SOURCE [--split FIELD]`, a <span style="color:grey">script</span> in TypeScript with zx (ADR 0002) | GDAL's `ogrinfo` <span style="color:grey">describes</span> <span style="color:grey">each</span> ***layer***: its <span style="color:grey">rows</span>, its <span style="color:grey">shape</span>, its <span style="color:grey">system</span> and its <span style="color:grey">fields</span>; the <span style="color:grey">command</span> <span style="color:grey">prints</span> a <span style="color:grey">starting</span> <span style="color:grey">pipeline</span> <span style="color:grey">file</span>, with the <span style="color:grey">next</span> <span style="color:grey">script</span>'s <span style="color:grey">number</span> |
| Write the pipeline file | The <span style="color:grey">maintainer</span> | <span style="color:grey">Edits</span> the <span style="color:grey">starting</span> <span style="color:grey">file</span>: <span style="color:grey">each</span> <span style="color:grey">table</span>'s ***schema***, <span style="color:grey">name</span> and filters, such as `data/macau.pipeline.json` |
| Run it | `npm run etl -- PIPELINE.json` | Extracts, <span style="color:grey">cleans</span> and <span style="color:grey">loads</span> <span style="color:grey">each</span> <span style="color:grey">table</span>; <span style="color:grey">writes</span> the <span style="color:grey">script</span>, such as `db/seed/0002-parks.sql`, and its <span style="color:grey">log</span> in `db/seed-logs/` |
| Review | The <span style="color:grey">maintainer</span> | <span style="color:grey">Reads</span> the <span style="color:grey">log</span> and the <span style="color:grey">script</span>, then <span style="color:grey">commits</span> both; <span style="color:grey">together</span> they <span style="color:grey">record</span> what <span style="color:grey">entered</span> the <span style="color:grey">database</span>, and what was <span style="color:grey">left</span> out and why |
| Seed | `Tessera seed`, which `npm start` <span style="color:grey">runs</span> at every <span style="color:grey">start</span> | DbUp <span style="color:grey">runs</span> <span style="color:grey">each</span> <span style="color:grey">new</span> <span style="color:grey">script</span> in a <span style="color:grey">transaction</span> of its <span style="color:grey">own</span> and <span style="color:grey">records</span> it in `tessera.schemaversions` |
| Publish | `npm run publish` | <span style="color:grey">Grants</span> the schemas and their <span style="color:grey">tables</span> to `tessera_reader` (US-24 c5) |

The filters, which <span style="color:grey">run</span> in the <span style="color:grey">order</span> the <span style="color:grey">pipeline</span> <span style="color:grey">file</span> <span style="color:grey">lists</span> them:

| Filter | Kind | What it does |
|---|---|---|
| `dropEmptyShapes` | <span style="color:grey">Shape</span> | A <span style="color:grey">row</span> with no <span style="color:grey">shape</span>, or an <span style="color:grey">empty</span> <span style="color:grey">one</span>, <span style="color:grey">fails</span> |
| `repairShapes` | <span style="color:grey">Shape</span> | An invalid <span style="color:grey">shape</span> is rebuilt with NetTopologySuite's `GeometryFixer`; <span style="color:grey">one</span> that <span style="color:grey">comes</span> out <span style="color:grey">empty</span> <span style="color:grey">fails</span> |
| `swapCoordinates` | <span style="color:grey">Shape</span> | A <span style="color:grey">shape</span> <span style="color:grey">outside</span> the <span style="color:grey">area</span> that <span style="color:grey">falls</span> <span style="color:grey">inside</span> it with its <span style="color:grey">two</span> <span style="color:grey">numbers</span> <span style="color:grey">swapped</span> is <span style="color:grey">swapped</span> <span style="color:grey">back</span> |
| `insideArea` | <span style="color:grey">Shape</span> | A <span style="color:grey">shape</span> that does not <span style="color:grey">touch</span> the <span style="color:grey">area</span>'s <span style="color:grey">box</span> <span style="color:grey">fails</span> |
| `tidyText` | <span style="color:grey">Text</span> | <span style="color:grey">Text</span> is <span style="color:grey">put</span> into Unicode's NFC <span style="color:grey">form</span>, <span style="color:grey">runs</span> of <span style="color:grey">spaces</span> <span style="color:grey">become</span> <span style="color:grey">one</span>, <span style="color:grey">ends</span> are trimmed, and <span style="color:grey">empty</span> <span style="color:grey">text</span> <span style="color:grey">becomes</span> <span style="color:grey">null</span> |
| `requireFields` | <span style="color:grey">Fields</span> | A <span style="color:grey">row</span> <span style="color:grey">missing</span> <span style="color:grey">any</span> of the <span style="color:grey">named</span> <span style="color:grey">fields</span>, or <span style="color:grey">holding</span> <span style="color:grey">only</span> <span style="color:grey">spaces</span> there, <span style="color:grey">fails</span> |
| `dropDuplicateIds` | Duplicates | A <span style="color:grey">row</span> that <span style="color:grey">repeats</span> an earlier <span style="color:grey">row</span>'s id <span style="color:grey">fails</span> |
| `dropNearDuplicates` | Duplicates | A <span style="color:grey">row</span> whose <span style="color:grey">name</span> <span style="color:grey">matches</span> an earlier <span style="color:grey">row</span>'s, ignoring <span style="color:grey">case</span> and <span style="color:grey">spaces</span>, <span style="color:grey">within</span> the <span style="color:grey">given</span> <span style="color:grey">metres</span>, <span style="color:grey">fails</span> |

A <span style="color:grey">row</span> that <span style="color:grey">fails</span> is <span style="color:grey">dropped</span> and logged, or, when its filter <span style="color:grey">says</span> `"onFail": "stop"`, <span style="color:grey">ends</span> the <span style="color:grey">run</span>. <span style="color:grey">After</span> its filters, a <span style="color:grey">table</span> <span style="color:grey">stops</span> the <span style="color:grey">run</span> when more than `droppedOverPercent` of its <span style="color:grey">rows</span> were <span style="color:grey">dropped</span>, 10 by <span style="color:grey">default</span>, or <span style="color:grey">fewer</span> than `rowsUnder` <span style="color:grey">remain</span>, 1 by <span style="color:grey">default</span>.

<span style="color:grey">Each</span> filter is a <span style="color:grey">function</span> from a <span style="color:grey">table</span>'s <span style="color:grey">rows</span> to an outcome: the <span style="color:grey">rows</span> it <span style="color:grey">kept</span>, a <span style="color:grey">log</span> <span style="color:grey">line</span> for <span style="color:grey">each</span> <span style="color:grey">row</span> it <span style="color:grey">fixed</span> or <span style="color:grey">dropped</span>, and, perhaps, a <span style="color:grey">reason</span> to <span style="color:grey">stop</span>. Filters <span style="color:grey">join</span> with `>>`, an operator that C# 14's extension <span style="color:grey">members</span> <span style="color:grey">add</span> to the filter <span style="color:grey">type</span>: `a >> b` <span style="color:grey">runs</span> `a`, then `b` on the <span style="color:grey">rows</span> `a` <span style="color:grey">kept</span>, <span style="color:grey">ends</span> at the <span style="color:grey">first</span> <span style="color:grey">stop</span>, and <span style="color:grey">joins</span> the <span style="color:grey">two</span> logs. The <span style="color:grey">pipeline</span> <span style="color:grey">file</span>'s <span style="color:grey">list</span> of filters <span style="color:grey">folds</span> into <span style="color:grey">one</span> such <span style="color:grey">chain</span>, and <span style="color:grey">code</span> may <span style="color:grey">build</span> the <span style="color:grey">same</span> <span style="color:grey">chain</span> by <span style="color:grey">hand</span> from <span style="color:grey">each</span> filter's <span style="color:grey">named</span> `Create` <span style="color:grey">function</span>. <span style="color:grey">Each</span> filter <span style="color:grey">lives</span> in a <span style="color:grey">file</span> of its <span style="color:grey">own</span> in `tools/Tessera.Etl/Filters/`, with a <span style="color:grey">record</span> of its <span style="color:grey">own</span> <span style="color:grey">settings</span>, so the <span style="color:grey">pipeline</span> <span style="color:grey">file</span> <span style="color:grey">refuses</span> a <span style="color:grey">setting</span> that <span style="color:grey">belongs</span> to another filter. The <span style="color:grey">script</span> <span style="color:grey">takes</span> its <span style="color:grey">columns</span> from the <span style="color:grey">cleaned</span> <span style="color:grey">rows</span>, so a filter may <span style="color:grey">add</span> a <span style="color:grey">column</span> or <span style="color:grey">remove</span> <span style="color:grey">one</span>.

<span style="color:grey">Each</span> <span style="color:grey">choice</span> GDAL is <span style="color:grey">asked</span> to <span style="color:grey">make</span>:

- **Longitude and latitude, flat.** Extraction <span style="color:grey">stores</span> every <span style="color:grey">shape</span> in EPSG:4326, <span style="color:grey">whatever</span> <span style="color:grey">system</span> the <span style="color:grey">source</span> <span style="color:grey">uses</span>, and <span style="color:grey">drops</span> heights and <span style="color:grey">measures</span> (`-dim XY`), which a <span style="color:grey">flat</span> ***tile*** <span style="color:grey">cannot</span> <span style="color:grey">carry</span>.
- **Straight lines.** <span style="color:grey">True</span> curves, such as a geodatabase's arcs, <span style="color:grey">become</span> <span style="color:grey">short</span> <span style="color:grey">straight</span> <span style="color:grey">lines</span> (`CONVERT_TO_LINEAR`), which PostGIS's <span style="color:grey">tile</span> <span style="color:grey">functions</span> <span style="color:grey">read</span>.
- **Words, not codes.** A geodatabase's <span style="color:grey">coded</span> <span style="color:grey">value</span> <span style="color:grey">becomes</span> its <span style="color:grey">description</span> (`-resolveDomains`), so a <span style="color:grey">tile</span> <span style="color:grey">carries</span> 'Museum', not 3.
- **INSERT, not COPY.** DbUp <span style="color:grey">sends</span> a <span style="color:grey">script</span> as <span style="color:grey">plain</span> SQL, so GDAL <span style="color:grey">writes</span> `INSERT` <span style="color:grey">statements</span> (`PG_USE_COPY NO`).
- **One transaction for each script.** GDAL <span style="color:grey">wraps</span> <span style="color:grey">each</span> <span style="color:grey">table</span> in `BEGIN` and `COMMIT`; the <span style="color:grey">pipeline</span> <span style="color:grey">takes</span> them out, so DbUp's <span style="color:grey">own</span> <span style="color:grey">transaction</span> <span style="color:grey">holds</span> the <span style="color:grey">whole</span> <span style="color:grey">script</span> and its ***journal*** <span style="color:grey">record</span>. A <span style="color:grey">script</span> that <span style="color:grey">fails</span> <span style="color:grey">changes</span> <span style="color:grey">nothing</span>, and <span style="color:grey">runs</span> <span style="color:grey">again</span> <span style="color:grey">once</span> <span style="color:grey">fixed</span>.
- **A numbered key.** GDAL <span style="color:grey">numbers</span> the <span style="color:grey">rows</span> 1, 2, 3 in the <span style="color:grey">order</span> the filters <span style="color:grey">kept</span> them, in a `fid` <span style="color:grey">column</span>. It is the <span style="color:grey">primary</span> <span style="color:grey">key</span>, which <span style="color:grey">fixes</span> the <span style="color:grey">order</span> of <span style="color:grey">features</span> in a <span style="color:grey">tile</span> (US-24 <span style="color:grey">test</span> 2). An `id` in the <span style="color:grey">source</span> <span style="color:grey">stays</span> a <span style="color:grey">column</span> of its <span style="color:grey">own</span>.
- **One kind of shape for lines and areas.** A <span style="color:grey">table</span> <span style="color:grey">marked</span> `lines` <span style="color:grey">stores</span> <span style="color:grey">one</span> <span style="color:grey">part</span> and <span style="color:grey">many</span> <span style="color:grey">parts</span> alike as many-part <span style="color:grey">shapes</span> (`PROMOTE_TO_MULTI`).
- **A new script replaces a table whole.** <span style="color:grey">Each</span> <span style="color:grey">script</span> <span style="color:grey">drops</span> a <span style="color:grey">table</span> <span style="color:grey">before</span> it <span style="color:grey">makes</span> it <span style="color:grey">again</span>. The <span style="color:grey">grant</span> <span style="color:grey">goes</span> with the <span style="color:grey">old</span> <span style="color:grey">table</span>, so the <span style="color:grey">new</span> <span style="color:grey">one</span> <span style="color:grey">waits</span> for the <span style="color:grey">publisher</span>.
- **Fresh statistics.** <span style="color:grey">Each</span> <span style="color:grey">table</span> <span style="color:grey">ends</span> with `ANALYZE`, so PostgreSQL <span style="color:grey">plans</span> the ***tile query*** <span style="color:grey">well</span> from the <span style="color:grey">first</span> <span style="color:grey">tile</span>.
- **A name used once.** The <span style="color:grey">pipeline</span> <span style="color:grey">refuses</span> a <span style="color:grey">script</span> <span style="color:grey">name</span> that <span style="color:grey">exists</span>, <span style="color:grey">since</span> DbUp <span style="color:grey">knows</span> a <span style="color:grey">script</span> by its <span style="color:grey">name</span> and would <span style="color:grey">never</span> <span style="color:grey">run</span> a <span style="color:grey">changed</span> <span style="color:grey">one</span>.

## Options considered

| Option | Why not |
|---|---|
| Python, with GeoPandas and Shapely | Rich <span style="color:grey">cleaning</span>, but a <span style="color:grey">third</span> <span style="color:grey">runtime</span> and its <span style="color:grey">packages</span> <span style="color:grey">beside</span> .NET and Node.js, and a <span style="color:grey">second</span> <span style="color:grey">language</span> for the <span style="color:grey">back</span> <span style="color:grey">end</span> |
| One `switch` on the filter's name, with one record of settings shared by every filter | A <span style="color:grey">new</span> filter <span style="color:grey">touches</span> <span style="color:grey">four</span> <span style="color:grey">places</span> in <span style="color:grey">one</span> <span style="color:grey">file</span>, and a <span style="color:grey">setting</span> meant for <span style="color:grey">one</span> filter <span style="color:grey">passes</span> unseen on every <span style="color:grey">other</span> |
| `ogr2ogr` alone, straight to SQL | No <span style="color:grey">place</span> for <span style="color:grey">cleaning</span> beyond a `-where`, and no <span style="color:grey">log</span> of what was <span style="color:grey">left</span> out |
| GDAL's own .NET bindings in place of `ogr2ogr` | <span style="color:grey">Native</span> <span style="color:grey">libraries</span> to <span style="color:grey">match</span> to <span style="color:grey">each</span> <span style="color:grey">machine</span>; `ogr2ogr` as a <span style="color:grey">program</span> is <span style="color:grey">one</span> <span style="color:grey">install</span>, or <span style="color:grey">one</span> Docker <span style="color:grey">image</span> |
| Run `ogr2ogr` straight into the database | No <span style="color:grey">script</span> to <span style="color:grey">review</span> or <span style="color:grey">commit</span>, and <span style="color:grey">nothing</span> <span style="color:grey">records</span> what <span style="color:grey">ran</span> |
| Flyway, Liquibase or Sqitch | <span style="color:grey">Each</span> <span style="color:grey">needs</span> a <span style="color:grey">runtime</span> or a <span style="color:grey">program</span> of its <span style="color:grey">own</span> <span style="color:grey">beside</span> .NET; DbUp is a <span style="color:grey">package</span> the <span style="color:grey">service</span> <span style="color:grey">loads</span> |
| `COPY` in the scripts | <span style="color:grey">Faster</span> to <span style="color:grey">load</span>, but DbUp <span style="color:grey">cannot</span> <span style="color:grey">feed</span> `COPY ... FROM STDIN` |

## Consequences

- The <span style="color:grey">database</span> has a <span style="color:grey">second</span> <span style="color:grey">door</span>. DbUp and the <span style="color:grey">seed</span> <span style="color:grey">open</span> their <span style="color:grey">own</span> <span style="color:grey">connections</span>, so <span style="color:grey">rule</span> 4 of ADR 0001, <span style="color:grey">one</span> <span style="color:grey">gate</span> to SQL, has <span style="color:grey">two</span> <span style="color:grey">doors</span>. The <span style="color:grey">seed</span>'s <span style="color:grey">one</span> SQL <span style="color:grey">text</span> of its <span style="color:grey">own</span>, the journal's schema, <span style="color:grey">lives</span> in `Queries.cs` with every <span style="color:grey">other</span>.
- <span style="color:grey">Each</span> <span style="color:grey">table</span> has a `fid` <span style="color:grey">column</span>, which its <span style="color:grey">tiles</span> <span style="color:grey">carry</span> as a <span style="color:grey">property</span>, <span style="color:grey">beside</span> <span style="color:grey">any</span> `id` from the <span style="color:grey">source</span>.
- A <span style="color:grey">replaced</span> <span style="color:grey">table</span> <span style="color:grey">leaves</span> the <span style="color:grey">map</span> until `npm run publish`. Meanwhile Nginx <span style="color:grey">serves</span> its <span style="color:grey">kept</span> <span style="color:grey">tiles</span> for <span style="color:grey">up</span> to `Tiles.CacheSeconds`.
