# ADR 0005: Cluster the places in the browser, from the vector tiles

| | |
|---|---|
| Status | <span style="color:grey">Accepted</span> |
| Date | 13 <span style="color:grey">October</span> 2026 |
| Decider | The <span style="color:grey">maintainer</span> |
| Covers | The <span style="color:grey">map</span>'s <span style="color:grey">front</span> <span style="color:grey">end</span>, in TypeScript, and the <span style="color:grey">tables</span> that <span style="color:grey">feed</span> it, in `nathanwh71/Tessera` |
| Stories | US-03, US-07, US-24, US-23, UI-10, UI-11, UI-17 (`docs/user-stories/user-stories.md`) |

## Decision

The <span style="color:grey">map</span> ***clusters*** the <span style="color:grey">places</span> <span style="color:grey">itself</span>, in the <span style="color:grey">browser</span>, from the ***vector tiles*** the <span style="color:grey">service</span> <span style="color:grey">already</span> <span style="color:grey">serves</span>. The <span style="color:grey">database</span> <span style="color:grey">keeps</span> <span style="color:grey">each</span> <span style="color:grey">place</span> as <span style="color:grey">typed</span> <span style="color:grey">point</span> geometry, and the ***tile*** API <span style="color:grey">stays</span> the <span style="color:grey">only</span> <span style="color:grey">way</span> a <span style="color:grey">client</span> <span style="color:grey">loads</span> <span style="color:grey">places</span>.

MapLibre GL JS clusters the <span style="color:grey">features</span> of a GeoJSON <span style="color:grey">source</span> <span style="color:grey">alone</span>; it <span style="color:grey">cannot</span> cluster a vector <span style="color:grey">tile</span> <span style="color:grey">source</span>. So the <span style="color:grey">map</span> bridges the <span style="color:grey">two</span>. `feedPlaces`, in the <span style="color:grey">map</span>'s `web/src/map/maplibre.ts`, <span style="color:grey">reads</span> the <span style="color:grey">places</span> from the <span style="color:grey">tiles</span> MapLibre has <span style="color:grey">loaded</span> for the ***layers*** that are on, <span style="color:grey">joins</span> them into <span style="color:grey">one</span> GeoJSON <span style="color:grey">collection</span>, and <span style="color:grey">hands</span> it to a clustered GeoJSON <span style="color:grey">source</span>:

| Step | Where | What it does |
|---|---|---|
| 1. Load the tiles | <span style="color:grey">One</span> vector <span style="color:grey">source</span> for <span style="color:grey">each</span> <span style="color:grey">layer</span> that is on, `/{layer}/{z}/{x}/{y}.pbf` (US-07) | MapLibre <span style="color:grey">asks</span> for <span style="color:grey">new</span> <span style="color:grey">tiles</span> <span style="color:grey">up</span> to <span style="color:grey">level</span> 16, and <span style="color:grey">stretches</span> the <span style="color:grey">last</span> <span style="color:grey">ones</span> <span style="color:grey">past</span> it |
| 2. Read their places | `map.querySourceFeatures`, <span style="color:grey">each</span> <span style="color:grey">time</span> a <span style="color:grey">tile</span> <span style="color:grey">source</span> <span style="color:grey">finishes</span> <span style="color:grey">loading</span> and <span style="color:grey">each</span> <span style="color:grey">time</span> the <span style="color:grey">map</span> <span style="color:grey">comes</span> to <span style="color:grey">rest</span> | <span style="color:grey">Gives</span> <span style="color:grey">each</span> <span style="color:grey">place</span> <span style="color:grey">back</span> in longitude and latitude |
| 3. Join them | `placeCollection`, in the <span style="color:grey">map</span>'s `web/src/map/places.ts`, a ***pure function*** | <span style="color:grey">Keeps</span> <span style="color:grey">each</span> <span style="color:grey">place</span> <span style="color:grey">once</span>, by its `id`, <span style="color:grey">since</span> a <span style="color:grey">place</span> <span style="color:grey">near</span> a <span style="color:grey">tile</span>'s <span style="color:grey">edge</span> <span style="color:grey">sits</span> in the buffer of its <span style="color:grey">neighbours</span> <span style="color:grey">too</span>. <span style="color:grey">Adds</span> its <span style="color:grey">layer</span>, its <span style="color:grey">group</span> and a <span style="color:grey">sort</span> <span style="color:grey">key</span> for UI-17 |
| 4. Cluster | <span style="color:grey">One</span> GeoJSON <span style="color:grey">source</span> with `cluster: true`, a radius of 48 pixels, clusters <span style="color:grey">up</span> to <span style="color:grey">level</span> 15 | <span style="color:grey">Counts</span> <span style="color:grey">each</span> <span style="color:grey">group</span>'s <span style="color:grey">places</span> in <span style="color:grey">each</span> cluster, for the <span style="color:grey">coloured</span> <span style="color:grey">ring</span> of UI-10 |
| 5. Skip work | A fingerprint of the <span style="color:grey">places</span>' ids | <span style="color:grey">Sets</span> the <span style="color:grey">source</span>'s <span style="color:grey">data</span> <span style="color:grey">only</span> when its <span style="color:grey">places</span> <span style="color:grey">change</span>, <span style="color:grey">since</span> <span style="color:grey">each</span> <span style="color:grey">new</span> <span style="color:grey">set</span> <span style="color:grey">makes</span> MapLibre cluster <span style="color:grey">again</span> |

<span style="color:grey">Two</span> <span style="color:grey">rules</span> <span style="color:grey">follow</span> for the <span style="color:grey">service</span>, its <span style="color:grey">Tiles</span> and <span style="color:grey">Seeding</span> ***modules*** (ADR 0001). **Every tile carries each place's `id`**, so the <span style="color:grey">map</span> can <span style="color:grey">keep</span> <span style="color:grey">each</span> <span style="color:grey">place</span> <span style="color:grey">once</span>. **Every tile carries each place's `name`**, so the <span style="color:grey">map</span> can <span style="color:grey">name</span> the <span style="color:grey">pins</span> <span style="color:grey">without</span> a <span style="color:grey">request</span> of its <span style="color:grey">own</span>. The <span style="color:grey">group</span> <span style="color:grey">needs</span> no <span style="color:grey">property</span>: the <span style="color:grey">layer</span>'s id <span style="color:grey">names</span> it, as `food.cafes` <span style="color:grey">names</span> the <span style="color:grey">food</span> <span style="color:grey">group</span> (US-24).

## Context

- **MapLibre's limit.** MapLibre GL JS clusters a GeoJSON <span style="color:grey">source</span> <span style="color:grey">alone</span>. UI-10 <span style="color:grey">asks</span> for <span style="color:grey">crowded</span> <span style="color:grey">places</span> to merge into clusters that <span style="color:grey">open</span> as the <span style="color:grey">visitor</span> <span style="color:grey">zooms</span>.
- **The tile API.** <span style="color:grey">Phase</span> Oct <span style="color:grey">keeps</span> <span style="color:grey">one</span> API, the <span style="color:grey">tile</span> of a <span style="color:grey">layer</span> (US-07). No <span style="color:grey">client</span>, the <span style="color:grey">map</span> <span style="color:grey">included</span>, <span style="color:grey">loads</span> a <span style="color:grey">list</span> of <span style="color:grey">layers</span> or a <span style="color:grey">whole</span> <span style="color:grey">layer</span> at <span style="color:grey">once</span>.
- **Typed geometry.** A <span style="color:grey">table</span> <span style="color:grey">becomes</span> a <span style="color:grey">layer</span> <span style="color:grey">only</span> with a <span style="color:grey">typed</span> geometry <span style="color:grey">column</span> and an ***SRID*** (US-03). <span style="color:grey">Each</span> <span style="color:grey">place</span> <span style="color:grey">table</span> <span style="color:grey">holds</span> <span style="color:grey">point</span> geometry in WGS 84, with a ***spatial index*** and <span style="color:grey">fresh</span> <span style="color:grey">statistics</span> (US-24, <span style="color:grey">criterion</span> 1), and PostGIS <span style="color:grey">builds</span> <span style="color:grey">each</span> <span style="color:grey">tile</span> from it with `ST_AsMVT` (US-07).
- **A small area.** Macau's 900 <span style="color:grey">places</span> <span style="color:grey">make</span> <span style="color:grey">about</span> 2,300 <span style="color:grey">different</span> <span style="color:grey">tiles</span> over the <span style="color:grey">levels</span> <span style="color:grey">visitors</span> <span style="color:grey">use</span>; a <span style="color:grey">whole</span> <span style="color:grey">layer</span> <span style="color:grey">holds</span> <span style="color:grey">about</span> 100 <span style="color:grey">places</span>.

## Options considered

| Option | For | Against |
|---|---|---|
| Cluster in the browser, from the vector tiles (chosen) | No <span style="color:grey">change</span> to the API, the <span style="color:grey">tables</span> or the <span style="color:grey">stories</span>. <span style="color:grey">Pins</span> can <span style="color:grey">move</span> out of a cluster as the <span style="color:grey">visitor</span> <span style="color:grey">zooms</span> (UI-10, <span style="color:grey">criterion</span> 2) | The <span style="color:grey">map</span> clusters <span style="color:grey">only</span> the <span style="color:grey">places</span> in the <span style="color:grey">tiles</span> it has <span style="color:grey">loaded</span>, so a cluster at the <span style="color:grey">edge</span> of the <span style="color:grey">screen</span> <span style="color:grey">counts</span> <span style="color:grey">fewer</span> <span style="color:grey">places</span> than <span style="color:grey">lie</span> beyond it, and <span style="color:grey">grows</span> as the <span style="color:grey">visitor</span> <span style="color:grey">pans</span> |
| Store the places as JSON in PostgreSQL | <span style="color:grey">None</span> for clustering: how the <span style="color:grey">database</span> <span style="color:grey">stores</span> a <span style="color:grey">place</span> <span style="color:grey">never</span> <span style="color:grey">reaches</span> the <span style="color:grey">browser</span>, which <span style="color:grey">receives</span> <span style="color:grey">tiles</span> | <span style="color:grey">Breaks</span> US-03, <span style="color:grey">since</span> a JSON <span style="color:grey">column</span> is no <span style="color:grey">typed</span> geometry and its <span style="color:grey">table</span> <span style="color:grey">becomes</span> no <span style="color:grey">layer</span>; US-24, <span style="color:grey">criterion</span> 1, <span style="color:grey">since</span> a JSON <span style="color:grey">column</span> <span style="color:grey">takes</span> no spatial index; and US-07, <span style="color:grey">since</span> `ST_AsMVT` <span style="color:grey">builds</span> <span style="color:grey">tiles</span> from geometry |
| A GeoJSON file for each layer, built by `ST_AsGeoJSON` | <span style="color:grey">One</span> <span style="color:grey">request</span> <span style="color:grey">loads</span> a <span style="color:grey">whole</span> <span style="color:grey">layer</span>, so the clusters <span style="color:grey">see</span> every <span style="color:grey">place</span>, with no <span style="color:grey">edge</span> <span style="color:grey">effect</span> | A <span style="color:grey">second</span> API, and a <span style="color:grey">new</span> <span style="color:grey">story</span>: in <span style="color:grey">Phase</span> Oct, <span style="color:grey">clients</span> <span style="color:grey">load</span> <span style="color:grey">tiles</span> <span style="color:grey">alone</span>. The geometry <span style="color:grey">stays</span> in the <span style="color:grey">tables</span> either <span style="color:grey">way</span> |
| Clusters built in the tiles, with `ST_ClusterDBSCAN` for each level | Every <span style="color:grey">client</span> <span style="color:grey">gets</span> the <span style="color:grey">same</span> clusters, with no <span style="color:grey">work</span> in the <span style="color:grey">browser</span> | A heavier ***tile query*** for every <span style="color:grey">tile</span>. The clusters <span style="color:grey">change</span> at <span style="color:grey">tile</span> <span style="color:grey">edges</span>, and UI-10's <span style="color:grey">pins</span> that <span style="color:grey">move</span> out of a cluster <span style="color:grey">need</span> <span style="color:grey">new</span> <span style="color:grey">work</span> |

## Consequences

**What gets easier**

- The <span style="color:grey">tables</span> and the <span style="color:grey">tile</span> <span style="color:grey">query</span> <span style="color:grey">serve</span> the clusters with no <span style="color:grey">change</span>.
- The <span style="color:grey">map</span>'s <span style="color:grey">tests</span> <span style="color:grey">check</span> the <span style="color:grey">join</span> and the cluster <span style="color:grey">counts</span> with <span style="color:grey">values</span> <span style="color:grey">alone</span>: `placeCollection` is <span style="color:grey">pure</span>, and `clusters.test.ts` <span style="color:grey">checks</span> the radius with Supercluster, the <span style="color:grey">library</span> MapLibre clusters with.
- A <span style="color:grey">visitor</span>'s <span style="color:grey">browser</span> does the clustering, so the <span style="color:grey">service</span>'s <span style="color:grey">work</span> <span style="color:grey">stays</span> <span style="color:grey">one</span> <span style="color:grey">cached</span> <span style="color:grey">tile</span> at a <span style="color:grey">time</span>.

**What gets harder**

- The <span style="color:grey">edge</span> <span style="color:grey">effect</span>: clusters <span style="color:grey">count</span> the <span style="color:grey">loaded</span> <span style="color:grey">tiles</span> <span style="color:grey">alone</span>, so a cluster <span style="color:grey">near</span> the <span style="color:grey">screen</span>'s <span style="color:grey">edge</span> can <span style="color:grey">change</span> as the <span style="color:grey">visitor</span> <span style="color:grey">pans</span>.
- The <span style="color:grey">map</span> rebuilds its clusters <span style="color:grey">whenever</span> the <span style="color:grey">loaded</span> <span style="color:grey">places</span> <span style="color:grey">change</span>, as <span style="color:grey">tiles</span> <span style="color:grey">arrive</span>.
- A <span style="color:grey">new</span> <span style="color:grey">style</span> <span style="color:grey">empties</span> the GeoJSON <span style="color:grey">source</span>, so the <span style="color:grey">map</span> must <span style="color:grey">feed</span> it <span style="color:grey">again</span> <span style="color:grey">after</span> <span style="color:grey">each</span> <span style="color:grey">style</span> <span style="color:grey">change</span>; `feedPlaces` <span style="color:grey">offers</span> `refresh` for that.

## When to revisit

- **The places grow.** At <span style="color:grey">many</span> <span style="color:grey">thousands</span> of <span style="color:grey">places</span>, the <span style="color:grey">join</span> and the reclustering in the <span style="color:grey">browser</span> may <span style="color:grey">cost</span> visible <span style="color:grey">time</span>; then clusters <span style="color:grey">built</span> in the <span style="color:grey">tiles</span> may <span style="color:grey">serve</span> <span style="color:grey">better</span>.
- **Visitors notice the edge effect.** If clusters that <span style="color:grey">change</span> at the <span style="color:grey">screen</span>'s <span style="color:grey">edge</span> confuse <span style="color:grey">visitors</span>, a GeoJSON <span style="color:grey">file</span> for <span style="color:grey">each</span> <span style="color:grey">layer</span> <span style="color:grey">removes</span> the <span style="color:grey">effect</span>, at the <span style="color:grey">cost</span> of a <span style="color:grey">new</span> <span style="color:grey">story</span>.
- **MapLibre clusters vector tiles.** If MapLibre GL JS <span style="color:grey">comes</span> to cluster a vector <span style="color:grey">source</span> <span style="color:grey">itself</span>, the bridge in `feedPlaces` can <span style="color:grey">go</span>.
