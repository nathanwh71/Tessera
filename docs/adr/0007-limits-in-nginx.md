# ADR 0007: Guard the door in Nginx, and keep resilience libraries out of the service

| | |
|---|---|
| Status | <span style="color:grey">Accepted</span> |
| Date | 15 <span style="color:grey">October</span> 2026 |
| Decider | The <span style="color:grey">maintainer</span> |
| Covers | The <span style="color:grey">service</span>, `nathanwh71/Tessera`, and Nginx in <span style="color:grey">front</span> of it |
| Related | S-07 and S-30; US-35; N-22, N-24, N-26 and N-28; ADR 0008 |

## Decision

Nginx <span style="color:grey">answers</span> <span style="color:grey">office</span> <span style="color:grey">machines</span> <span style="color:grey">alone</span> and <span style="color:grey">caps</span> what <span style="color:grey">each</span> may <span style="color:grey">ask</span>. The <span style="color:grey">service</span> <span style="color:grey">adds</span> no <span style="color:grey">resilience</span> <span style="color:grey">library</span>: it <span style="color:grey">keeps</span> no <span style="color:grey">limits</span>, no <span style="color:grey">retries</span> and no <span style="color:grey">circuit</span> <span style="color:grey">breakers</span> of its <span style="color:grey">own</span>.

| Need | Where it lives | How |
|---|---|---|
| Office machines alone (S-07) | Nginx | `geo` <span style="color:grey">sets</span> `$office` from `TESSERA_OFFICE_NETWORK`; <span style="color:grey">any</span> <span style="color:grey">other</span> <span style="color:grey">address</span> <span style="color:grey">gets</span> 403 |
| A rate for each visitor (S-30) | Nginx | `limit_req`: 100 ***tiles*** a <span style="color:grey">second</span>, a burst of 300, then 429 |
| Requests at once for each visitor (S-30) | Nginx | `limit_conn`: 32, then 429 |
| Queries served in the order they arrive | Npgsql's <span style="color:grey">pool</span> (N-26) | <span style="color:grey">Nothing</span> to <span style="color:grey">add</span> |
| A database that is down or hangs | Nginx's <span style="color:grey">kept</span> <span style="color:grey">tiles</span>, and the <span style="color:grey">service</span>'s 503 with `Retry-After` (N-22, N-28) | <span style="color:grey">Nothing</span> to <span style="color:grey">add</span> |
| Retries, timeouts and breakers on outgoing calls | Polly, <span style="color:grey">through</span> Microsoft.Extensions.Resilience | <span style="color:grey">Only</span> when Tessera <span style="color:grey">calls</span> another <span style="color:grey">service</span> |

## Why

- **The door is Nginx's.** Every <span style="color:grey">request</span> <span style="color:grey">passes</span> <span style="color:grey">through</span> Nginx <span style="color:grey">first</span>, so a <span style="color:grey">refusal</span> there <span style="color:grey">costs</span> the <span style="color:grey">service</span> <span style="color:grey">nothing</span>, and a stranger <span style="color:grey">never</span> <span style="color:grey">reaches</span> the ***cache*** either. <span style="color:grey">Each</span> <span style="color:grey">rule</span> is a <span style="color:grey">few</span> <span style="color:grey">lines</span> of <span style="color:grey">settings</span>, <span style="color:grey">tested</span> on millions of <span style="color:grey">sites</span>.
- **Each visitor is one address.** WSL2's ***mirrored networking*** <span style="color:grey">lets</span> Nginx <span style="color:grey">see</span> <span style="color:grey">each</span> <span style="color:grey">office</span> <span style="color:grey">machine</span>'s <span style="color:grey">own</span> <span style="color:grey">address</span> (US-35), so a <span style="color:grey">limit</span> <span style="color:grey">follows</span> a <span style="color:grey">machine</span>, however <span style="color:grey">many</span> <span style="color:grey">connections</span> its <span style="color:grey">browser</span> <span style="color:grey">opens</span>.
- **The numbers fit the map.** A <span style="color:grey">fresh</span> <span style="color:grey">view</span> of <span style="color:grey">nine</span> ***layers*** <span style="color:grey">asks</span> for <span style="color:grey">about</span> a <span style="color:grey">hundred</span> <span style="color:grey">tiles</span> at <span style="color:grey">once</span>, so a burst of 300 <span style="color:grey">lets</span> it <span style="color:grey">through</span>; 100 <span style="color:grey">tiles</span> a <span style="color:grey">second</span> <span style="color:grey">covers</span> steady <span style="color:grey">panning</span>. The <span style="color:grey">service</span> <span style="color:grey">builds</span> <span style="color:grey">about</span> 2,400 <span style="color:grey">tiles</span> a <span style="color:grey">second</span> from the <span style="color:grey">database</span>, on <span style="color:grey">two</span> <span style="color:grey">processors</span>, so 24 <span style="color:grey">machines</span> at the <span style="color:grey">full</span> <span style="color:grey">rate</span> could <span style="color:grey">fill</span> it.
- **The machine itself goes free.** <span style="color:grey">Requests</span> from 127.0.0.1, such as `npm start`'s <span style="color:grey">health</span> <span style="color:grey">check</span>, <span style="color:grey">meet</span> no <span style="color:grey">rule</span> and no <span style="color:grey">limit</span>.
- **The pool keeps order already.** Npgsql <span style="color:grey">lends</span> <span style="color:grey">connections</span> in the <span style="color:grey">order</span> <span style="color:grey">requests</span> <span style="color:grey">ask</span> for them, and the <span style="color:grey">tests</span> of N-26 <span style="color:grey">prove</span> it.
- **Breakers stay out.** A <span style="color:grey">circuit</span> <span style="color:grey">breaker</span> <span style="color:grey">judges</span> <span style="color:grey">only</span> from <span style="color:grey">failed</span> <span style="color:grey">requests</span>, and <span style="color:grey">reopens</span> by <span style="color:grey">trial</span> <span style="color:grey">requests</span> that would <span style="color:grey">meet</span> an <span style="color:grey">empty</span> <span style="color:grey">pool</span>. The one-second <span style="color:grey">ping</span> <span style="color:grey">tells</span> `/health` the <span style="color:grey">database</span>'s <span style="color:grey">state</span> with no <span style="color:grey">traffic</span> at all.

## Options considered

| Option | Why not |
|---|---|
| ASP.NET Core's rate limiters in the service | <span style="color:grey">Each</span> ***copy of the service*** would <span style="color:grey">count</span> <span style="color:grey">apart</span>, so <span style="color:grey">two</span> <span style="color:grey">copies</span> would <span style="color:grey">let</span> a <span style="color:grey">visitor</span> <span style="color:grey">through</span> <span style="color:grey">twice</span>; and a <span style="color:grey">refused</span> <span style="color:grey">request</span> would <span style="color:grey">still</span> <span style="color:grey">cost</span> the <span style="color:grey">service</span> a <span style="color:grey">little</span> <span style="color:grey">work</span> |
| Polly, with a breaker on the tile query | A <span style="color:grey">dependency</span>, <span style="color:grey">new</span> <span style="color:grey">tests</span> and <span style="color:grey">repeated</span> <span style="color:grey">load</span> <span style="color:grey">runs</span>, for a <span style="color:grey">gap</span> Nginx's <span style="color:grey">kept</span> <span style="color:grey">tiles</span> <span style="color:grey">already</span> <span style="color:grey">close</span> |
| The Windows firewall alone, for the office rule | It can <span style="color:grey">refuse</span> strangers, but <span style="color:grey">cannot</span> <span style="color:grey">cap</span> a <span style="color:grey">visitor</span>, and the <span style="color:grey">rule</span> would <span style="color:grey">live</span> <span style="color:grey">outside</span> the repository |

## Consequences

- `npm start` <span style="color:grey">refuses</span> to <span style="color:grey">start</span> <span style="color:grey">without</span> `TESSERA_OFFICE_NETWORK`, or with a <span style="color:grey">range</span> wider than `/8`.
- A <span style="color:grey">visitor</span> <span style="color:grey">past</span> the <span style="color:grey">limit</span> <span style="color:grey">sees</span> <span style="color:grey">tiles</span> <span style="color:grey">missing</span> until the <span style="color:grey">rate</span> <span style="color:grey">catches</span> <span style="color:grey">up</span>; MapLibre <span style="color:grey">asks</span> for them <span style="color:grey">again</span> when the <span style="color:grey">view</span> <span style="color:grey">next</span> <span style="color:grey">moves</span>.
- The <span style="color:grey">office</span> <span style="color:grey">rule</span> <span style="color:grey">allows</span> <span style="color:grey">one</span> <span style="color:grey">range</span>. A <span style="color:grey">second</span> <span style="color:grey">range</span>, such as a VPN's, <span style="color:grey">needs</span> <span style="color:grey">one</span> more <span style="color:grey">line</span> in `nginx/default.conf.template`.
- The <span style="color:grey">edge</span> <span style="color:grey">checks</span> <span style="color:grey">prove</span> all <span style="color:grey">three</span> <span style="color:grey">rules</span>: the <span style="color:grey">office</span> <span style="color:grey">rule</span>, the <span style="color:grey">rate</span>, and the <span style="color:grey">cap</span> on <span style="color:grey">requests</span> at <span style="color:grey">once</span>, the <span style="color:grey">last</span> with forty <span style="color:grey">requests</span> for a <span style="color:grey">tile</span> that <span style="color:grey">takes</span> <span style="color:grey">two</span> <span style="color:grey">seconds</span> to <span style="color:grey">build</span>.

## When to revisit

- The <span style="color:grey">office</span> <span style="color:grey">joins</span> a <span style="color:grey">second</span> <span style="color:grey">network</span>, such as a VPN.
- The <span style="color:grey">map</span> <span style="color:grey">asks</span> for <span style="color:grey">many</span> more <span style="color:grey">tiles</span> <span style="color:grey">per</span> <span style="color:grey">view</span>, or the <span style="color:grey">office</span> <span style="color:grey">grows</span> <span style="color:grey">past</span> 20 <span style="color:grey">machines</span>: <span style="color:grey">measure</span> <span style="color:grey">again</span> and <span style="color:grey">set</span> <span style="color:grey">new</span> <span style="color:grey">numbers</span>.
- Tessera <span style="color:grey">begins</span> to <span style="color:grey">call</span> another <span style="color:grey">service</span> over the <span style="color:grey">network</span>, where <span style="color:grey">retries</span>, <span style="color:grey">timeouts</span> and <span style="color:grey">breakers</span> <span style="color:grey">earn</span> their <span style="color:grey">place</span>.
