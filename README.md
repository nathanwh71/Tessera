# Tessera

Tessera is a <span style="color:grey">small</span> <span style="color:grey">web</span> <span style="color:grey">service</span> that <span style="color:grey">serves</span> a <span style="color:grey">map</span> of <span style="color:grey">places</span> as ***tiles***. It <span style="color:grey">reads</span> <span style="color:grey">tables</span> from a <span style="color:grey">database</span>, <span style="color:grey">cuts</span> them into <span style="color:grey">map</span> <span style="color:grey">tiles</span> on <span style="color:grey">request</span>, and <span style="color:grey">answers</span> every <span style="color:grey">machine</span> in the <span style="color:grey">office</span> on <span style="color:grey">port</span> 80, <span style="color:grey">through</span> Nginx. This <span style="color:grey">build</span>, <span style="color:grey">Phase</span> Oct, <span style="color:grey">serves</span> the 900 <span style="color:grey">places</span> of Macau in <span style="color:grey">nine</span> ***layers***, and <span style="color:grey">shows</span> them on a <span style="color:grey">map</span> at `/`.

A **tile** is <span style="color:grey">one</span> <span style="color:grey">square</span> of a <span style="color:grey">map</span> at <span style="color:grey">one</span> ***zoom level***. A <span style="color:grey">web</span> <span style="color:grey">map</span> is <span style="color:grey">made</span> of <span style="color:grey">thousands</span> of them, and the <span style="color:grey">browser</span> <span style="color:grey">asks</span> for <span style="color:grey">only</span> the <span style="color:grey">ones</span> on the <span style="color:grey">screen</span>. Tessera <span style="color:grey">makes</span> <span style="color:grey">each</span> <span style="color:grey">tile</span> from the <span style="color:grey">database</span> the <span style="color:grey">first</span> <span style="color:grey">time</span> a <span style="color:grey">map</span> <span style="color:grey">asks</span> for it; Nginx <span style="color:grey">keeps</span> it for a <span style="color:grey">minute</span> and <span style="color:grey">hands</span> the <span style="color:grey">same</span> <span style="color:grey">copy</span> to everyone who <span style="color:grey">asks</span> in that <span style="color:grey">time</span>.

## Where the settings live

<span style="color:grey">Machines</span>, <span style="color:grey">ports</span> and <span style="color:grey">passwords</span> <span style="color:grey">come</span> from ***environment variables***: <span style="color:grey">values</span> the <span style="color:grey">operating</span> <span style="color:grey">system</span> <span style="color:grey">hands</span> a <span style="color:grey">program</span> when it <span style="color:grey">starts</span>. The <span style="color:grey">service</span> <span style="color:grey">refuses</span> to <span style="color:grey">start</span> <span style="color:grey">without</span> its <span style="color:grey">database</span>'s <span style="color:grey">address</span> and <span style="color:grey">names</span> every <span style="color:grey">problem</span> it <span style="color:grey">finds</span> (US-00 c4); it <span style="color:grey">starts</span> <span style="color:grey">whether</span> or not the <span style="color:grey">database</span> <span style="color:grey">answers</span> yet, and <span style="color:grey">answers</span> 503 until it does (N-23). ## Adding places

The <span style="color:grey">places</span> <span style="color:grey">reach</span> the <span style="color:grey">database</span> as SQL <span style="color:grey">scripts</span> in `db/seed`, which DbUp <span style="color:grey">runs</span> <span style="color:grey">once</span> <span style="color:grey">each</span>, in the <span style="color:grey">order</span> of their <span style="color:grey">names</span> (ADR 0009). A **pipeline file** <span style="color:grey">turns</span> a <span style="color:grey">file</span> of <span style="color:grey">places</span> into the <span style="color:grey">next</span> <span style="color:grey">script</span>, <span style="color:grey">cleaning</span> it on the <span style="color:grey">way</span>: GDAL extracts <span style="color:grey">each</span> <span style="color:grey">table</span>, filters <span style="color:grey">clean</span> its <span style="color:grey">rows</span>, and GDAL <span style="color:grey">writes</span> the SQL. To <span style="color:grey">add</span> <span style="color:grey">places</span>:

1. Inspect the <span style="color:grey">data</span>, such as `npm run inspect -- data/parks.gdb`, and <span style="color:grey">save</span> the <span style="color:grey">starting</span> <span style="color:grey">pipeline</span> <span style="color:grey">file</span> it <span style="color:grey">prints</span> <span style="color:grey">beside</span> the <span style="color:grey">data</span>, such as `data/parks.pipeline.json`. Then <span style="color:grey">set</span> <span style="color:grey">each</span> <span style="color:grey">table</span>'s ***schema*** and <span style="color:grey">name</span>, and its filters. It <span style="color:grey">names</span> the <span style="color:grey">source</span>, the <span style="color:grey">script</span> to <span style="color:grey">write</span>, and <span style="color:grey">each</span> <span style="color:grey">table</span> with its filters. GDAL <span style="color:grey">reads</span> <span style="color:grey">file</span> geodatabases, GeoJSON, shapefiles, GeoPackages, CSV and more, and <span style="color:grey">stores</span> every <span style="color:grey">shape</span> in longitude and latitude.
2. <span style="color:grey">Run</span> it: `npm run etl -- data/parks.pipeline.json`. It <span style="color:grey">writes</span> the <span style="color:grey">script</span>, such as `db/seed/0002-parks.sql`, and a <span style="color:grey">log</span> of what <span style="color:grey">each</span> filter did to <span style="color:grey">each</span> <span style="color:grey">row</span>, in `db/seed-logs/`.
3. <span style="color:grey">Read</span> the <span style="color:grey">log</span> and the <span style="color:grey">script</span>, then <span style="color:grey">commit</span> both. <span style="color:grey">Never</span> <span style="color:grey">change</span> a <span style="color:grey">script</span>'s SQL <span style="color:grey">once</span> it has <span style="color:grey">run</span>: DbUp would not <span style="color:grey">run</span> it <span style="color:grey">again</span>. A <span style="color:grey">comment</span> may <span style="color:grey">change</span>, <span style="color:grey">since</span> DbUp <span style="color:grey">knows</span> a <span style="color:grey">script</span> by its <span style="color:grey">name</span> <span style="color:grey">alone</span>. <span style="color:grey">Put</span> <span style="color:grey">new</span> or <span style="color:grey">corrected</span> <span style="color:grey">data</span> in a <span style="color:grey">new</span> <span style="color:grey">script</span>, with the <span style="color:grey">next</span> <span style="color:grey">number</span>.
4. <span style="color:grey">Run</span> `npm start`, or `Tessera seed` as `tessera_publisher`, then `npm run publish`. A <span style="color:grey">script</span> that <span style="color:grey">replaces</span> a <span style="color:grey">table</span> <span style="color:grey">takes</span> its <span style="color:grey">grant</span> with it, so the <span style="color:grey">table</span> <span style="color:grey">waits</span> for the <span style="color:grey">publish</span>.

A <span style="color:grey">table</span> of a geodatabase <span style="color:grey">names</span> its ***feature class*** as `layer`; a <span style="color:grey">table</span> <span style="color:grey">cut</span> from <span style="color:grey">one</span> <span style="color:grey">file</span> <span style="color:grey">names</span> its <span style="color:grey">rows</span> with `where`, as `data/macau.pipeline.json` does for the <span style="color:grey">nine</span> Macau <span style="color:grey">layers</span>. A <span style="color:grey">pipeline</span> <span style="color:grey">file</span> for a geodatabase, `data/parks.gdb`, <span style="color:grey">looks</span> <span style="color:grey">like</span> this:

```json
{
  "source": "data/parks.gdb",
  "output": "db/seed/0002-parks.sql",
  "stopWhen": { "droppedOverPercent": 5 },
  "tables": [
    { "table": "food.cafes", "layer": "Cafes", "filters": [
      { "filter": "dropEmptyShapes", "onFail": "stop" },
      { "filter": "swapCoordinates" },
      { "filter": "insideArea", "onFail": "stop" },
      { "filter": "tidyText" },
      { "filter": "requireFields", "fields": ["id", "name"] },
      { "filter": "dropDuplicateIds", "field": "id", "onFail": "stop" },
      { "filter": "dropNearDuplicates", "field": "name", "metres": 25 } ] },
    { "table": "outdoors.parks", "layer": "Parks", "lines": true, "filters": [ { "filter": "repairShapes" } ] }
  ]
}
```

| Filter | What it does |
|---|---|
| `dropEmptyShapes` | A <span style="color:grey">row</span> with no <span style="color:grey">shape</span>, or an <span style="color:grey">empty</span> <span style="color:grey">one</span>, <span style="color:grey">fails</span> |
| `repairShapes` | An invalid <span style="color:grey">shape</span>, such as an <span style="color:grey">area</span> whose <span style="color:grey">edge</span> <span style="color:grey">crosses</span> <span style="color:grey">itself</span>, is <span style="color:grey">repaired</span>; <span style="color:grey">one</span> that <span style="color:grey">cannot</span> be <span style="color:grey">repaired</span> <span style="color:grey">fails</span> |
| `swapCoordinates` | A <span style="color:grey">shape</span> <span style="color:grey">outside</span> the <span style="color:grey">area</span> that <span style="color:grey">falls</span> <span style="color:grey">inside</span> it with longitude and latitude <span style="color:grey">swapped</span> is <span style="color:grey">swapped</span> <span style="color:grey">back</span> |
| `insideArea` | A <span style="color:grey">shape</span> that does not <span style="color:grey">touch</span> the <span style="color:grey">area</span>'s <span style="color:grey">box</span> <span style="color:grey">fails</span> |
| `tidyText` | <span style="color:grey">Text</span> is <span style="color:grey">put</span> into <span style="color:grey">one</span> Unicode <span style="color:grey">form</span>, <span style="color:grey">runs</span> of <span style="color:grey">spaces</span> <span style="color:grey">become</span> <span style="color:grey">one</span>, <span style="color:grey">ends</span> are trimmed, and <span style="color:grey">empty</span> <span style="color:grey">text</span> <span style="color:grey">becomes</span> <span style="color:grey">null</span>; `fields` <span style="color:grey">limits</span> it to <span style="color:grey">some</span> <span style="color:grey">columns</span> |
| `requireFields` | A <span style="color:grey">row</span> <span style="color:grey">missing</span> <span style="color:grey">any</span> of `fields`, or <span style="color:grey">holding</span> <span style="color:grey">only</span> <span style="color:grey">spaces</span> there, <span style="color:grey">fails</span> |
| `dropDuplicateIds` | A <span style="color:grey">row</span> that <span style="color:grey">repeats</span> an earlier <span style="color:grey">row</span>'s `field` <span style="color:grey">fails</span> |
| `dropNearDuplicates` | A <span style="color:grey">row</span> whose `field` <span style="color:grey">matches</span> an earlier <span style="color:grey">row</span>'s, <span style="color:grey">within</span> `metres` of it, <span style="color:grey">fails</span> |

Filters <span style="color:grey">run</span> in the <span style="color:grey">order</span> <span style="color:grey">listed</span>, <span style="color:grey">each</span> on the <span style="color:grey">rows</span> the <span style="color:grey">one</span> <span style="color:grey">before</span> <span style="color:grey">kept</span>. A <span style="color:grey">row</span> that <span style="color:grey">fails</span> is <span style="color:grey">dropped</span>, or, with `"onFail": "stop"`, <span style="color:grey">ends</span> the <span style="color:grey">whole</span> <span style="color:grey">run</span>. A <span style="color:grey">table</span> <span style="color:grey">also</span> <span style="color:grey">stops</span> the <span style="color:grey">run</span> when more than `droppedOverPercent` of its <span style="color:grey">rows</span> were <span style="color:grey">dropped</span>, 10 by <span style="color:grey">default</span>, or <span style="color:grey">fewer</span> than `rowsUnder` <span style="color:grey">remain</span>, 1 by <span style="color:grey">default</span>; `stopWhen` <span style="color:grey">sets</span> them for the <span style="color:grey">whole</span> <span style="color:grey">file</span> or for <span style="color:grey">one</span> <span style="color:grey">table</span>. A <span style="color:grey">stopped</span> <span style="color:grey">run</span> <span style="color:grey">writes</span> no <span style="color:grey">script</span>, but <span style="color:grey">always</span> <span style="color:grey">writes</span> its <span style="color:grey">log</span>. The <span style="color:grey">area</span> <span style="color:grey">comes</span> from `tessera.json`, or from the <span style="color:grey">pipeline</span>'s <span style="color:grey">own</span> `area`. `lines: true` <span style="color:grey">stores</span> <span style="color:grey">lines</span> and <span style="color:grey">areas</span> as many-part <span style="color:grey">shapes</span>, so <span style="color:grey">one</span> <span style="color:grey">table</span> <span style="color:grey">holds</span> both <span style="color:grey">kinds</span>.

**Adding a filter.** <span style="color:grey">Each</span> filter is <span style="color:grey">one</span> <span style="color:grey">file</span> in `tools/Tessera.Etl/Filters/`. It <span style="color:grey">holds</span> the filter's <span style="color:grey">name</span>, what it does, a <span style="color:grey">record</span> of its <span style="color:grey">own</span> <span style="color:grey">settings</span>, its <span style="color:grey">checks</span>, and a `Create` <span style="color:grey">function</span> that <span style="color:grey">returns</span> the filter: a <span style="color:grey">function</span> from a <span style="color:grey">table</span>'s <span style="color:grey">rows</span> to the <span style="color:grey">rows</span> it <span style="color:grey">keeps</span> and a <span style="color:grey">log</span> of what it did. A <span style="color:grey">new</span> filter is <span style="color:grey">one</span> <span style="color:grey">new</span> <span style="color:grey">file</span>, <span style="color:grey">modelled</span> on `InsideArea.cs`, and <span style="color:grey">one</span> <span style="color:grey">line</span> in `Filters/All.cs`. <span style="color:grey">Each</span> filter <span style="color:grey">reads</span> <span style="color:grey">only</span> its <span style="color:grey">own</span> <span style="color:grey">settings</span>, so the <span style="color:grey">pipeline</span> <span style="color:grey">file</span> <span style="color:grey">refuses</span> a <span style="color:grey">setting</span> that <span style="color:grey">belongs</span> to another filter, or <span style="color:grey">one</span> that is <span style="color:grey">missing</span>.

**Filters in code.** Filters <span style="color:grey">join</span> with `>>`, which <span style="color:grey">runs</span> the <span style="color:grey">left</span> <span style="color:grey">one</span>, then the <span style="color:grey">right</span> <span style="color:grey">one</span> on the <span style="color:grey">rows</span> it <span style="color:grey">kept</span>, and <span style="color:grey">stops</span> at the <span style="color:grey">first</span> <span style="color:grey">stop</span>:

```csharp
var cleanCafes =
    DropEmptyShapes.Create(OnFail.Stop)
    >> SwapCoordinates.Create(macau)
    >> InsideArea.Create(macau, OnFail.Stop)
    >> TidyText.Create()
    >> RequireFields.Create(["id", "name"]);
```

The <span style="color:grey">pipeline</span> <span style="color:grey">file</span> <span style="color:grey">builds</span> the <span style="color:grey">same</span> <span style="color:grey">chain</span> from its <span style="color:grey">list</span>. A filter may <span style="color:grey">also</span> <span style="color:grey">add</span> or <span style="color:grey">remove</span> a <span style="color:grey">column</span>: the <span style="color:grey">script</span> <span style="color:grey">takes</span> its <span style="color:grey">columns</span> from the <span style="color:grey">cleaned</span> <span style="color:grey">rows</span>.

## How the database keeps the service safe

Tessera <span style="color:grey">follows</span> pg_tileserv's <span style="color:grey">rule</span>: the <span style="color:grey">database</span> <span style="color:grey">decides</span> what the <span style="color:grey">map</span> <span style="color:grey">shows</span>. The <span style="color:grey">service</span> <span style="color:grey">signs</span> in as `tessera_reader`, a <span style="color:grey">role</span> that may <span style="color:grey">only</span> <span style="color:grey">read</span>, and a <span style="color:grey">table</span> <span style="color:grey">becomes</span> a <span style="color:grey">layer</span> <span style="color:grey">only</span> when that <span style="color:grey">role</span> is <span style="color:grey">granted</span> it. The <span style="color:grey">seed</span> <span style="color:grey">signs</span> in as `tessera_publisher`, which <span style="color:grey">owns</span> the <span style="color:grey">tables</span> but <span style="color:grey">never</span> <span style="color:grey">grants</span> them on its <span style="color:grey">own</span>; <span style="color:grey">publishing</span> is the <span style="color:grey">publisher</span>'s <span style="color:grey">own</span> <span style="color:grey">act</span>.

<span style="color:grey">Two</span> <span style="color:grey">attacks</span> are <span style="color:grey">closed</span> by <span style="color:grey">design</span>. Every <span style="color:grey">value</span> from a <span style="color:grey">request</span> <span style="color:grey">travels</span> <span style="color:grey">beside</span> the <span style="color:grey">query</span> as a ***parameter***, <span style="color:grey">never</span> <span style="color:grey">inside</span> its <span style="color:grey">text</span>, and every <span style="color:grey">name</span> <span style="color:grey">enters</span> the <span style="color:grey">text</span> <span style="color:grey">quoted</span>, <span style="color:grey">through</span> <span style="color:grey">one</span> <span style="color:grey">function</span>, `Queries.Quote`; so no <span style="color:grey">request</span> can smuggle in a <span style="color:grey">command</span> (***SQL injection***, S-01). Nginx <span style="color:grey">refuses</span> an <span style="color:grey">address</span> it <span style="color:grey">cannot</span> <span style="color:grey">read</span>, and the <span style="color:grey">service</span> <span style="color:grey">matches</span> <span style="color:grey">routes</span> on the <span style="color:grey">address</span> as <span style="color:grey">sent</span>, so a disguised <span style="color:grey">address</span> <span style="color:grey">reaches</span> no <span style="color:grey">route</span> (a <span style="color:grey">malformed</span> URL, S-06).
